# ボックス割引率チェッカー（/box/）の決まり

セールボックスの値段と中身から、主要なアイテムだけで数えた割引率と「お得度」（これまでの最安値の達成度）を出す。
データ集め・計算の経緯は `.claude/drafts/box-checker/README.md`（自動では読まれない）。

## 計算（2026-11-11タダシさん決定・確定仕様）
- **数えるのは主要の6つだけ**: ふかそうち・スーパーふかそうち・プレミアムバトルパス・リモートレイドパス・マックス粒子パック・ダイキノコ。ほしのかけら・しあわせタマゴ・ボールなどのおまけは計算に入れない（選ぶ窓にも出さない）。ボックスの値段をまるごと主要のアイテムの分として数える
- 割引率＝1 −（ボックスの値段 ÷ 主要のアイテムの単品の合計）。おまけ入りの箱ではゲーム内の「◯%OFF」と合わない＝狙いどおり（使い方に書いてある）
- **お得度＝単品の合計を0%・最安値の合計を100%として、ボックスの値段がどこにあるか**。100%を超えることもある
- **最安値は、ボックスの値段 ÷ 主要のアイテムの単品の合計 を単品の値段に掛けた値**（最安値の表もこのやり方でそろえる。おまけを割り引いて数えた値と混ぜない）。基準に選ぶのは中身のほとんどが1つのアイテムの箱
- 最安値の表（切りのよい数で持つ＝画面の数字で手計算が合う）: ふかそうち60・スーパーふかそうち80（タマゴボックス7000）／プレミアムバトルパス55（ハイパーレイドボックス5425）／リモートレイドパス140（リモートレイドボックス490）／マックス粒子パック103・ダイキノコ274（散策ボックス1300）
- 単品の値段: ふかそうち150・スーパーふかそうち200・バトルパス100・リモートレイドパス195・マックス粒子パック150・ダイキノコ400
- **最安値を変えるとき・アイテムを足すときは必ずタダシさんに確認する**。推測で値段を埋めない。新しいスクショは `.claude/drafts/box-checker/` に出どころごとのファイルで控え、`python3 best_price_main.py` で並べる
- **マックス粒子は「1パック」で数える。「1個」と書かない**。1パック＝800（ボックスに2400とあれば3パック）
- コインと円の両方を入れたら、割引率は安いほうの値段で計算する。コインの買い方（まとめ売り）は端末に保存（`site_box_bundle`）。入力は `site_box_state`

## 見た目
- 箱の絵は `box/giftbox.js`（`GiftBox.svg(種類,{size})`・ゲーム内の箱を手本にした9種類）。**リモートレイドパスが入れば青いガラスの箱**（ゲームと同じ）。黒（ロケットレーダー入り）・金に紺（すごいわざマシン入り）は、そのアイテムを選べないので出さない（`GIFT_NEVER`）。それ以外は開くたびにランダム
- 面の模様は0〜100の正方形で描いて行列で面へ貼る。ツールのアイコンも同じ箱の絵（タダシさん承認）
- 「最安値より安い／高い」とは書かない。最安値は基準
- **割引率・お得度の数字は「押し出し」の立体**（2026-11-12タダシさんが5案からA案を選択・`.v3d`＝金／`.g`＝緑／`.r`＝赤・`.sm`＝下の帯の小さい数字）。真ん中で明暗が折れるグラデーション＋下へ3段の厚み。ライトはベタ塗り＋軽い影。お得度の数字は半円の SVG の外の文字（`.gnum`）
- 中身の内訳の帯の下に、色・アイテム名・単品の合計・割合の一覧（`.legend`）。外したアイテムは斜線の四角と取り消し線
- **アイテムの色は固定**（2026-11-15タダシさん指示・`COLORS`）: ふかそうち＝ほぼ黄色（`#f6c443`・オレンジは暗く見えるため2026-11-16に変更）・スーパーふかそうち＝紫・プレミアムバトルパス＝緑・リモートレイドパス＝青・マックス粒子パック＝ピンク・ダイキノコ＝赤とマゼンタの中間。行の左の帯・内訳の帯・一覧の印に使う。入れた順番で色を変えない
- 削除は赤いゴミ箱のボタン（×は掛け算と紛れる）。個数の左は常に「−」（1のときは押せない）
- ランキングではないので、広告の枠は A（タイトルの下）だけ
- **結果の枠は「ガラスと金」**（2026-11-15タダシさんが3案からA案を選択・CSSは `.res` で始まる塊・変数 `--rbg`／`--rring`／`--tbg` などはダークとライトの両方）: 金と紫の1pxの縁取り・ガラスの光沢のパネル・見出しに金の英字（DISCOUNT／VALUE／SCALE／CONTENTS）・メーターは目盛り7本と筒の光の筋と先端の玉（`gauge()`）・ものさしは10等分の刻みと金の札・内訳は光沢の帯と宝石形の印と点線の明細。見本は `scratchpad/mock-boxres.html`（B・C案も入っている）
- **2つのパネルは中身を幅いっぱいに**（2026-11-16タダシさん指摘「余白ができすぎ」）: パネルを `container-type:inline-size` にし、割引率の数字は `clamp(58px,42cqw,96px)`・上下の真ん中・左右も真ん中、**メーターは240度の弧**（半円だと上が空くため・`gauge()` の A0=210・SW=240）で幅いっぱい（最大230px）・お得度の数字は弧の真ん中に `clamp(30px,23cqw,54px)`・「最安値の達成度」は弧の切れ目に入れる。画面の幅で大きさが変わる

## 画像の保存（開発者だけ・2026-11-15タダシさん指示・動画用）
- **結果**は、ほかのツールと同じ snap.js の枠ごとのボタン（📷 画像を保存／1920×1440）で保存する（`.card.res`）
- **値段と中身は、画像専用のカード（`.scard`）で1枚に**（2026-11-16タダシさん指示「入力欄のスクショではなく動画用に綺麗にまとめる」）: 中身の枠の下の `#inSnap`（開発者だけ表示）を押すと、その時の入力から箱の絵・値段（金の押し出し）・中身（色の帯・宝石形の印・名前・単品の値段・大きな「×個数」・外したものは「要らない」）・単品で買うと◯コイン、をまとめたカードを画面の外に組み立てて `GonaviSnap.devSave` で保存し、取り除く。結果の枠と同じ「ガラスと金」・常にダークの色。**部品の名前は `sc` で始める**（`.pr`・`.it`・`.big`・`.yen` などページの別の部品とぶつかって崩れたため）。ファイル名は「…_値段と中身_日時.png」
- 一般の人には何も出ない（`GonaviSnap.isDev()` が偽ならボタンを出さない）
