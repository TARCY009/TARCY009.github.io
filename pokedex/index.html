この図鑑でわかること

ポケモンを選ぶと、種族値・最大CP・弱点/耐性・わざ性能が1画面で確認できます。わざの行をタップすると、発生時間や能力変化まで含めた詳細ウィンドウが開きます。

最大CP

PL50・個体値15/15/15のCPです(相棒ブーストのPL51は含みません)。メガシンカ・ゲンシカイキのポケモンには、メガLv4(メガレベル最大でPL上限+2＝PL52)のCPも並べて出します。

スーパー/ハイパー最大SCP

そのリーグのCP上限(1500/2500)に収まる個体値・PL(〜50)の全組み合わせのうち、いちばん高いSCPです。SCP＝攻撃・防御・HPを総合したPvP向けの評価値で、個体値チェッカーや対面シミュレーターの理想個体と同じ基準です。交換できないポケモンの個体値下限(10)や、レイド産のPL下限も織り込んでいます(収まる個体がいなければ「—」)。

弱点・耐性

受けるダメージの倍率でまとめています。×2.56=二重弱点 / ×1.6=弱点 / ×0.63=耐性 / ×0.39=二重耐性 / ×0.24=三重耐性相当。ポケモンGOには「効果なし(無効)」が無く、原作の無効は×0.39として扱われます。

ジム・レイドのわざ性能

  • 威力 … タイプ一致(1.2倍)込みの値を赤字で示します(不一致は素の威力)
  • 時間 … わざ全体の秒数
  • EPS … 1秒あたりのゲージ増加(ノーマルアタック)
  • DPS … 1秒あたりのダメージ(威力÷時間)
  • SPアタックのわざ名の下のバーはゲージの本数(1〜3本)です
  • ダメージ発生までの時間は、わざをタップした詳細ウィンドウで確認できます

トレーナーバトルのわざ性能

  • ゲージ … 1発で増えるゲージ量(ノーマルアタック) ／ 消費 … 撃つのに使うゲージ量(SPアタック)
  • ターン … 1ターン=0.5秒
  • EPT/DPT … 1ターンあたりのゲージ増加/ダメージ
  • DPE … 消費ゲージ1あたりのダメージ(高いほど効率がよい)

特別わざ(*)

わざ名の後ろの*は、レガシーわざ・特別なわざ(コミュニティデイ限定など)の目印です。通常のわざマシンでは覚えられず、イベント期間かすごいわざマシンが必要です。

メガの「＋」わざ（追加SPアタック）

わざ名の最後が「+」で追加の印が付くものは、メガシンカ中だけ使える3本目のSPアタックです（2026年8月31日から）。ふつうの2本とは別枠なので、強さ順には混ぜず表の先頭に置いています。条件を満たせば自動で覚えます（わざマシン不要）。覚えるのはメガLv4（スーパーマックスレベル）に到達できる13匹だけです。レイドとGOバトルリーグで使えますが、ジムに配置されたポケモンとのジムバトルでは使えません。メガレベルが上がるほど威力が上がります（Lv1＝1.0倍／Lv2＝1.1倍／Lv3＝1.2倍／Lv4（スーパーマックス）＝1.3倍）。表の上のメガLvで切り替えられます（既定はLv4・サイト内の他のツールにも引き継がれます）。

絞り込みと並べ替え

検索欄の下の「タイプ・地方で絞り込む」から使えます。

  • タイプ … 2つまで選べて、2つ選ぶと複合タイプ(両方を持つポケモン)に絞れます
  • 弱点 … 選んだタイプの攻撃が弱点(×1.6以上)のポケモンに絞れます(例: でんきを選ぶと、でんきわざで攻撃したいポケモンの一覧)
  • 地方 … 全国図鑑の番号で分けています。アローラ・ガラルなどの地方フォルムは元のポケモンの地方に入ります
  • しぼる … 伝説・幻／最終進化だけに絞れます
  • 並べ替え … 一覧を最大CP・攻撃・防御・HPの高い順に並べ替えられます

わざから探す

検索欄にわざの名前を入れると候補に「わざ」が出て、選ぶとそのわざを覚えるポケモンの一覧に切り替わります。名前の後ろの*は、そのポケモンにとって特別なわざ(レガシー)である印です。タイプなどの絞り込み・並べ替えとも組み合わせられます。

のせていないわざ・わるあがき

やつあたり・おんがえし(シャドウ/ライトポケモン専用)は一覧にのせていません。SPアタックを覚えないポケモン(コイキングなど)は、実戦で自動発動するわるあがき(ジム・レイド=3ゲージ／トレーナーバトル=消費100)を載せています。
